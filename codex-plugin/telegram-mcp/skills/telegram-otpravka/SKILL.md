# Telegram — отправка

Уточни неоднозначного адресата через `list_chats`. Если пользователь просит только сформулировать текст или не разрешил немедленную отправку явно, верни либо сохрани черновик и ничего не отправляй. Для разрешённой отправки используй самый узкий подходящий инструмент и сообщи адресата и результат. Медиа можно загружать только из `TELEGRAM_MCP_UPLOAD_DIR`. Редактирование, отмена и удаление должны быть разрешены активным профилем; опасные действия дополнительно требуют нового подтверждения точной цели.
