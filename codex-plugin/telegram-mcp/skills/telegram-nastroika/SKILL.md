# Telegram — настройка

Проводи пользователя через локальную настройку по одному решению за раз.

1. Установи зависимости проекта и запусти `telegram-mcp setup`. Рекомендуй профиль `read-only`, если пользователь не назвал потребность в отправке или управлении.
2. Объясни выбранный профиль и покажи результат `telegram-mcp permissions` до входа.
3. Пользователь получает собственные `api_id` и `api_hash` на `my.telegram.org`, а реквизиты, код входа и 2FA вводит только в локальном терминале при `telegram-mcp login --account <имя>`.
4. Никогда не проси вставлять секреты в Codex. Не просматривай `.env`, зашифрованные файлы сессий, записи keyring и значения master key.
5. Для безопасной проверки используй `telegram-mcp diagnostics` или MCP-инструмент диагностики. После изменения установки плагина или разрешений начни новую задачу Codex, чтобы схема инструментов загрузилась заново.
6. Для Claude Code и другого MCP-клиента регистрируй `telegram_mcp_server.py` либо `telegram-mcp serve` как локальный STDIO-сервер; не включай HTTP/SSE.
