# Команды Telegram для Codex

Плагин можно использовать двумя способами:

- нативно — упомянуть `@Telegram` или просто попросить: «Покажи непрочитанные сообщения в Telegram»;
- явно — выбрать навык в меню либо указать его команду `$telegram-mcp:...`.

Видимые названия и описания русские. Внутренние идентификаторы после `$telegram-mcp:` записаны латиницей, потому что формат навыков Codex допускает только латинские буквы, цифры и дефисы.

## Telegram — Все команды

Команда: `$telegram-mcp:telegram`

Универсальная точка входа. Подходит, когда задача сочетает несколько действий или пользователь не хочет выбирать режим вручную. Плагин сам проверит активные разрешения и выберет доступные инструменты.

Примеры: «Найди переписку по проекту и подготовь ответ», «Покажи непрочитанные и выдели срочные».

## Telegram — Чтение

Команда: `$telegram-mcp:telegram-chtenie`

Безопасный режим для списка чатов, чтения сообщений, непрочитанных, контекста переписки, поиска по одному чату или всему Telegram, сводок и анализа активности. Сам по себе ничего не отправляет, не редактирует и не удаляет.

Примеры: «Сделай сводку непрочитанных», «Найди сообщения про договор», «Покажи контекст вокруг сообщения».

## Telegram — Отправка

Команда: `$telegram-mcp:telegram-otpravka`

Используется для черновиков, отправки и ответов, пересылки, редактирования, реакций, отметки прочитанным, запланированных сообщений, медиа и опросов. Сработают только включённые пользователем возможности. Если явного разрешения на немедленную отправку нет, навык готовит черновик.

Примеры: «Подготовь вежливый ответ», «Отправь согласованный текст Ивану», «Запланируй сообщение на завтра».

## Telegram — Управление

Команда: `$telegram-mcp:telegram-upravlenie`

Предназначена для групп и каналов: создание, приглашение участников, переименование, закрепление и открепление сообщений, удаление участника и выход из чата. Для опасных действий плагин отдельно покажет точную цель и попросит подтверждение.

Примеры: «Создай группу для проекта», «Закрепи это сообщение», «Пригласи участника в канал».

## Telegram — Настройка

Команда: `$telegram-mcp:telegram-nastroika`

Помогает выбрать профиль доступа (`read-only`, `assistant`, `power-user` или `custom`), включить отдельные возможности, добавить аккаунт, проверить диагностику и безопасное хранение сессии. Секреты и коды входа вводятся только в локальном терминале, а не в чате с ИИ.

Примеры: «Оставь только чтение», «Добавь рабочий аккаунт», «Покажи, какие разрешения включены».
