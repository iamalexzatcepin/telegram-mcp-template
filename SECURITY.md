# Security policy

## Модель безопасности

Этот проект предназначен только для локального STDIO-запуска. Он не реализует
HTTP/SSE, сетевую авторизацию, общий хостинг или многопользовательский доступ.

В MCP зарегистрированы только три операции чтения: `list_chats`, `read_chat` и
`search_chat`. Изменения этого набора должны проходить отдельную проверку.

## Секретные данные

Никогда не публикуйте и не передавайте:

- `.env` и `TELEGRAM_API_HASH`;
- коды входа и облачный пароль Telegram;
- `sessions/*.session`;
- копии диска или архивы, содержащие эти файлы.

Если сессия могла утечь, завершите её в Telegram: `Settings → Devices`, затем
создайте новую локальную сессию.

## Сообщить об уязвимости

Не создавайте публичный issue с секретами или рабочим proof of concept. Используйте
GitHub Security Advisory репозитория либо свяжитесь с владельцем приватно.

## Не поддерживается

- публичное размещение сервера;
- проброс через туннели;
- общий сервер для нескольких людей;
- отправка, редактирование и удаление Telegram-сообщений.
